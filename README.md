# ReChat-sender

Windows端免登录QQ/微信，一号多管理聊天软件，基于HalloChat-CSharp（WPF）二次开发。其核心目标是实现多平台消息的收发，而非完整的聊天软件功能。后端由专门的 ReChat-provider 处理，前端只需专注于与后端交互和用户界面。

## 核心功能

- **多平台消息收发**：支持 QQ、微信等平台的消息收发
- **一号多管理**：使用一个账号管理多个聊天平台
- **免登录功能**：无需单独登录各个平台
- **与 ReChat-provider 后端交互**：通过后端处理实现多平台消息管理
- **实时消息同步**：多平台消息实时同步，支持跨平台消息转发

## 技术栈

- **前端**：WPF (.NET Framework 4.8)
- **后端通信**：HTTP/WebSocket
- **数据处理**：Newtonsoft.Json
- **开发环境**：Visual Studio 2022

## 项目结构

- **MainWindow.xaml/cs**：主窗口界面和逻辑
- **Views/LoginWindow.xaml/cs**：登录窗口界面和逻辑
- **Services/**：服务层，包含以下服务：
  - **ApiService**：API 通信服务，处理 HTTP 请求和 WebSocket 连接
  - **AuthService**：认证服务，处理登录、登出等认证相关操作
  - **MessageService**：消息服务，处理消息发送、接收和管理
  - **AccountService**：账号管理服务，处理平台账号的添加、删除和更新
  - **SyncService**：同步服务，处理多平台消息同步和跨平台消息转发

## 安装和运行

1. 确保已安装 Visual Studio 2022
2. 克隆项目代码
3. 打开解决方案文件
4. 构建项目
5. 运行应用程序
6. 输入账号密码登录（默认连接到本地 ReChat-provider 后端）

## 服务层说明

### ApiService
- 提供 HTTP 请求和 WebSocket 连接功能
- 支持 GetAsync 和 PostAsync 方法
- 处理连接状态管理和错误处理

### AuthService
- 处理用户登录、登出
- 支持令牌刷新和认证状态检查
- 提供自动登录设置功能

### MessageService
- 处理消息发送和接收
- 支持消息历史查询和未读消息获取
- 提供消息状态管理和格式化功能

### AccountService
- 管理平台账号的添加、删除和更新
- 支持平台连接测试
- 提供支持的平台列表

### SyncService
- 实现多平台消息同步
- 支持跨平台消息转发
- 处理同步状态管理
